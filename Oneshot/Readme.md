# 🐍 Oneshot

> One file, zero ambition — just flexing Python fundamentals.

A single-file walkthrough of core Python concepts, written while brushing off the rust. No frameworks, no dependencies, no delusions of grandeur — just `print()` statements and mild self-discovery.

## 📂 Topics Covered

Because apparently one file wasn't enough to hold this much enthusiasm for basics:

- Variables, types & constants
- String manipulation & slicing
- Operators (arithmetic, comparison, logical)
- Input & type conversion
- Conditionals (`if` / `elif` / `else`)
- Lists, tuples, and 2D lists (matrix)
- Loops (`for`, `while`) & nested loops
- Dictionaries & sets
- Functions, `*args` / `**kwargs`, global variables (and the chaos they cause)
- Error handling (`try` / `except` / `finally`) — for when things inevitably go sideways

## 🛠️ Requirements

- Python 3.9+ (uses built-in type hints like `list[str]`, so no ancient interpreters allowed)

## 🚀 How to Run

```bash
python oneshot.py
```

The script will prompt you for a few inputs (name, age, temperature, score) along the way. Answer honestly — the code won't judge, but it might do math with your answers.
