# Python One-Shot Practice 🐍

A single-file walkthrough of core Python concepts, written while learning for beginners.

## Topics Covered

- Variables, types & constants
- String manipulation & slicing
- Operators (arithmetic, comparison, logical)
- Input & type conversion
- Conditionals (`if` / `elif` / `else`)
- Lists, tuples, and 2D lists (matrix)
- Loops (`for`, `while`) & nested loops
- Dictionaries & sets
- Functions, `*args` / `**kwargs`, global variables
- Error handling (`try` / `except` / `finally`)

## Requirements

- Python 3.9+ (uses built-in type hints like `list[str]`)

## How to Run

```bash
python oneshot.py
```

The script will prompt you for a few inputs (name, age, temperature, score) along the way.

## Files

- `oneshot.py` — the complete practice script (single file, no dependencies)
