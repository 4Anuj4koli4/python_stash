# 🔐 CryptoLab

A simple Python-based **cryptography playground** for experimenting with different encryption, decryption, encoding, and hashing techniques.

The project is mainly built for **learning and understanding how different cryptographic methods work from scratch**.

## 🚀 Currently Supported

### Ciphers

- Caesar Cipher
- Atbash Cipher
- Vigenère Cipher
- ROT13
- XOR Cipher
- Affine Cipher
- Rail Fence Cipher
- Reverse Cipher
- Substitution Cipher
- Bacon Cipher

### Modes

- 🔒 Encryption
- 🔓 Decryption

## 🛠️ Tech Used

- Python
- No external cryptography libraries for the basic ciphers

## 📌 Purpose

This project is being developed as a learning project to:

- Practice Python
- Understand classical cryptography
- Learn encryption and decryption concepts
- Experiment with different algorithms
- Build a foundation for a future web-based **CryptoLab**

Run the program:

```bash
python crypto_lab.py
```

## ⚠️ Disclaimer

The ciphers in this project are mainly for **educational purposes**. Classical ciphers such as Caesar, Atbash, and Vigenère are **not secure for protecting real-world sensitive data**.
