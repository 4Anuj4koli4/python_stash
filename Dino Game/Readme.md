# Python Dino Game 🦖

A simple Chrome-style "T-Rex" runner game built with Python and Pygame.

## Requirements

- Python 3.7+
- Pygame

## Installation

```bash
pip install pygame
```

## How to Run

```bash
python dino_game.py
```

## Controls

| Key           | Action                    |
| ------------- | ------------------------- |
| `SPACE` / `↑` | Jump                      |
| `↓`           | Duck                      |
| `R`           | Restart (after game over) |
| `ESC`         | Quit                      |

## Gameplay

- Jump over cacti and duck under flying birds.
- The game speeds up the longer you survive.
- Your score and high score are shown in-game.
- Colliding with an obstacle ends the run — press `R` to try again.

## Files

- `dino.py` — the complete game (single file, no extra assets needed)
